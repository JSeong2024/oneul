## 1. 처리하는 정보와 목적

- **서버 설정:** 서버·텍스트 채널·음성 채널·관리 역할·공용 플레이어 및 배너 메시지의 ID와 서버 언어를 처리하고 저장합니다. 서버별 작동 환경 유지에 사용합니다.
- **일시적 이용 정보:** 요청자의 사용자 ID, 채널·음성 연결·권한 상태, 개인 언어와 개인 화면 연결 정보를 필요한 동안 메모리에서 처리합니다. 명령 및 버튼의 사용 권한 확인과 응답에 사용하며 사용자별 이용 내역 파일을 만들지 않습니다.
- **재생 정보:** 신청한 링크·곡 제목·길이·표지·공급원·공개 업로더 정보, 현재 곡·완료·실패 항목을 포함한 세션 목록을 메모리에서 처리합니다. 이용자가 첨부한 음악 파일은 열거나 내려받지 않습니다. 곡 정보에 신청자 ID를 붙여 보관하지 않습니다.
- **운영 로그:** UTC 발생 시각, 버전, 오류 코드, 처리 단계, 임의 오류 번호와 반복 수를 기록합니다. 사용자·서버·채널 ID, 원본 예외 내용, 메시지 본문, 곡 제목·URL과 파일명은 운영 로그에 기록하지 않습니다.

TAKO는 음악 신청용 채널에서 지원하는 음원 링크만 처리합니다. Discord 이벤트에 첨부파일 정보가 포함되더라도 해당 파일을 열거나 다운로드·재생하지 않습니다. 일반 채팅을 대화 기록으로 보관하지 않으며, 음성 대화를 녹음하거나 음성 인식을 하지 않습니다. 봇 내부 문의·신고·답변 기능과 DM 자동 응답은 운영하지 않습니다. 일반 DM 수신 이벤트를 구독하지 않으며 DM에서 명령어를 제공하지 않습니다. 이는 Discord 자체의 메시지 보관이나 DM 전송 화면을 차단한다는 뜻은 아닙니다.

## 2. 표시와 외부 서비스 이용

곡 정보와 재생목록은 해당 Discord 채널 또는 기능을 이용할 수 있는 구성원에게 표시될 수 있습니다. 신청자 표시는 제공하지 않습니다. 이용자가 직접 작성한 신청 메시지·첨부파일의 공개 범위는 Discord 채널 권한을 따릅니다.

음악 정보와 음원 조회에는 요청한 링크·콘텐츠 식별자 등을 YouTube 또는 SoundCloud로 전송합니다. 실행 장치의 접속 정보가 해당 서비스에 전달될 수 있으며 Discord 사용자 ID를 음악 조회 요청에 추가하지 않습니다. SoundCloud는 운영자의 앱 자격 증명으로 공개 자료만 조회하며 이용자의 SoundCloud 계정 로그인은 요구하지 않습니다. Spotify 연동은 제공하지 않습니다.

봇은 운영자 DM이나 별도 Discord 채널로 오류 로그를 자동 전송하지 않습니다. 이용자가 오류 확인을 위해 자료를 직접 제출하는 경우에는 제출한 연락처와 내용이 운영자에게 전달됩니다. 이메일 등 외부 창구의 자료는 목적 달성 후 불필요해지면 삭제하며 Discord 문의 연결 파일로 보관하지 않습니다.

Discord와 음원 서비스 이용 과정에서 해외 처리가 발생할 수 있습니다. 운영자는 정보를 판매하거나 광고·사용자 성향 분석에 이용하지 않습니다. 새로운 처리 수탁자나 보관 방식을 도입할 경우 관련 내용을 공개하고 필요한 절차를 거칩니다.

## 3. 보관과 삭제

서버 설정은 서비스를 제공하는 동안 보관하며, 봇이 서버에서 제거되면 정리합니다. 봇이 꺼져 있을 때 제거된 경우 다음 접속 시 확인합니다. 삭제 요청을 확인한 경우에도 더 이상 필요하지 않은 정보를 삭제합니다.

개인 언어·개인 화면·재생 정보는 파일로 저장하지 않습니다. 개인 언어는 재시작 시 초기화되며 `/언어`에서 기본값으로 돌릴 수 있습니다. 개인 화면은 교체·만료·종료 시 연결 정보를 정리합니다. 일반적인 음성 연결 종료와 봇 종료 시 해당 음악 세션을 초기화하며, 예기치 않은 연결 끊김이나 진단 재연결에서는 전체 세션 목록과 상태가 같은 실행 중 남을 수 있습니다. 계속 실행하더라도 이용 정보는 생성 시각을 기준으로 최대 7일까지만 유지합니다.

로그는 봇 폴더의 `logs`에 기록합니다. 시작할 때 이전 실행 로그를 삭제하고, 실행 중에는 UTC 시간 단위로 나누어 구간 시작부터 24시간이 지난 파일을 정리합니다. 60초 간격으로 확인하므로 정상 실행에서도 삭제 확인 시점만큼 지연될 수 있습니다. 파일에 새 기록이 추가되어도 기한은 연장하지 않습니다. 삭제 실패 시 다음 확인에서 재시도하며 운영자는 권한·장애를 해결해야 합니다. 로그 정리는 재생 중인 음원이나 재생 상태를 변경하지 않습니다.

YouTube 재생 실패 시 임시로 받은 음원은 해당 재생 종료 후 삭제합니다. SoundCloud 음원은 별도의 다운로드 재시도를 하지 않습니다. FFmpeg의 실행 중 진단 임시 파일은 처리가 끝나면 닫고, 강제 종료로 남은 파일은 다음 시작 시 정리합니다. 도구 캐시·실행 파일은 동작 환경에 필요한 동안 보관합니다.

이전 문의 기능의 연결 파일은 업데이트 후 시작 시 제거합니다. 기존 삭제 예약에서 확인한 봇 작성 사본은 삭제를 시도하며 실패 항목은 실행 중 메모리에서 재시도합니다. 이전 폴더·백업, 예약에 없는 과거 사본, 이용자 원본 메시지는 이 자동 정리의 대상이 아니므로 운영자가 별도로 확인해야 합니다.

법적 보관 의무가 실제로 확인된 경우 필요한 최소 자료만 해당 목적·기간 안에서 별도로 보호하고 이후 삭제합니다. 단순히 사안이 중대하다는 이유만으로 일반 로그의 자동 삭제를 중단하지 않습니다. 운영을 종료할 때에는 법적 보관 의무가 없는 자료를 지체 없이 삭제합니다.
