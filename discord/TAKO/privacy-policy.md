# TAKO 개인정보 처리방침

- 시행일: 2026.11.16
- 개인정보 처리 주체: **ONEUL**
- 개인정보 문의: eins2019@gmail.com

TAKO 운영자는 음악 재생, 서버 설정, 문의와 신고 처리에 필요한 정보를 아래와 같이 처리합니다. 본 방침은 위 운영 주체가 운영하는 TAKO에 적용됩니다. 배포된 코드를 다른 사람이 별도로 실행하는 봇에는 해당 운영자의 처리방침이 적용됩니다.

## 1. 처리하는 정보와 목적

**음악 신청과 재생**
Discord 사용자 ID, 서버·채널 ID, 음성 채널 접속 상태, 명령어와 선택 항목, 신청한 링크, 곡 제목·길이·썸네일, 첨부파일과 파일명을 처리합니다. 신청자 확인, 채널 연결, 재생목록 관리와 이전 곡 다시 재생에 사용합니다. 이전 곡 기록에는 위 곡 정보와 신청자 정보가 포함되며, 같은 영상 또는 파일은 하나만 남겨 최근 50곡까지 보관합니다.

**서버 설정**
서버 ID, 전용 텍스트 채널·기본 음성 채널·오류 수신 채널 ID, 배너·플레이어 메시지 ID, 서버 기본 언어와 지정한 TAKO 관리 역할 ID를 저장합니다. 설정 변경 권한을 확인하기 위해 Discord의 권한과 역할 정보도 사용합니다.

**개인 언어와 개인 조작창**
Discord 사용자 ID와 선택한 언어를 봇 실행 중 메모리에 보관합니다. 개인 응답, 조작창과 진단창 등을 선택한 언어로 표시하기 위해 사용합니다. 개인 언어를 선택하지 않으면 해당 서버의 기본 언어를 따르며, 개인 선택은 같은 봇이 제공되는 다른 서버에서도 적용됩니다.

**문의와 신고**
제출한 유형, 제목, 내용, 관련 링크·오류 번호, 사용자 ID, 서버 ID, 언어와 접수 번호를 처리합니다. 접수 내용을 운영자에게 전달하고 답변을 보내기 위해 사용합니다.

**오류 확인과 운영**
발생 시각, 봇 버전, 오류 번호·유형·내용, 서버·음성 채널 ID, 당시 곡 제목과 접속 상태 등의 기록을 처리합니다. 장애 확인, 복구와 서비스 오용 방지에 사용합니다. 반복 문의와 DM 안내를 제한하기 위해 사용자 ID와 최근 요청 시각도 실행 중 메모리에서 처리합니다.

Discord 연결 과정에서 권한 범위 안의 메시지, 기본 프로필 및 채널 상태 정보가 전달될 수 있습니다. TAKO는 음악 신청, 명령어 처리, 문의 안내 등에 필요한 정보를 사용하며 일반 채팅 내용을 별도의 대화 기록으로 저장하지 않습니다. 일반 DM도 운영자에게 자동 전달하지 않습니다.

TAKO는 음성 대화를 녹음하거나 음성 인식을 하지 않습니다. 실명, 주민등록번호, 결제정보의 입력을 요구하지 않습니다.

## 2. 정보가 표시되거나 전달되는 범위

재생 중인 곡, 신청자 표시와 대기 중인 곡은 플레이어가 게시된 채널의 접근 권한에 따라 다른 구성원에게 보일 수 있습니다. 재생목록과 이전 곡 기록은 해당 서버에서 기능을 이용할 수 있는 구성원이 조회할 수 있으며, 신청자 본인만 볼 수 있는 기록은 아닙니다. 신청 링크와 원본 첨부파일의 공개 범위도 해당 Discord 채널의 권한을 따릅니다.

문의와 신고는 봇 운영자가 지정한 수신 채널 또는 운영자 DM으로 전달합니다. 오류 리포트는 서버의 지정 채널, 봇 운영자의 수신 채널 또는 DM으로 전달합니다. 해당 채널에 접근 권한이 있는 담당자가 내용을 열람할 수 있습니다. 서버 관리자는 오류 수신 채널을 담당자만 볼 수 있도록 설정해야 합니다.

음악 정보 조회와 재생을 위해 요청한 영상의 주소·식별자 등을 YouTube에 전송합니다. 이때 봇 실행 장치의 접속 정보가 외부 서비스에 전달될 수 있습니다. TAKO가 음악 조회 요청에 이용자의 Discord ID를 추가해 전송하지는 않습니다.

Discord 메시지·첨부파일·DM의 보관과 전송, YouTube의 콘텐츠 제공 과정에는 각 서비스의 개인정보 처리방침이 적용됩니다. 이 과정에서 정보가 해외에서 처리될 수 있습니다.

운영자는 개인정보를 판매하거나 맞춤형 광고에 이용하지 않습니다. 위 기능 제공, 이용자가 요청한 전달, 관계 법령에 따른 의무 이행 외의 목적으로 외부에 제공하지 않습니다. 별도의 호스팅 사업자나 처리 수탁자를 도입하는 경우에는 관련 처리 내용을 공개하고 필요한 절차를 거칩니다.

## 3. 보관과 삭제

**재생 정보와 음악 파일**
현재 곡, 대기 중인 곡, 최근 50곡의 이전 곡 기록과 신청자 정보는 실행 중 메모리에 보관하며 파일로 저장하지 않습니다. 수동·자동으로 음성 연결을 종료하거나 봇을 종료하면 초기화합니다. 예기치 않게 음성 연결이 끊기면 현재 곡과 이전 곡 기록은 초기화되지만, 대기 중인 곡과 해당 임시 파일은 같은 실행 중 다시 이용할 수 있도록 남아 있을 수 있습니다. 진단 기능으로 음성 연결을 다시 설정하는 경우에는 재생목록과 이전 곡 기록을 유지합니다.

업로드한 음악 임시 파일은 재생과 이전 곡 다시 재생에 사용하며, 일반적인 음성 연결 종료 또는 봇 종료 시 삭제합니다. YouTube 재생을 위해 임시로 받은 음원은 해당 재생이 끝나면 삭제하며, 이전 곡 기록에는 원래 영상 링크를 사용합니다. 비정상 종료 등으로 남은 임시 파일은 다음 시작 시 정리합니다.

**서버 설정**
서버에서 서비스를 제공하는 동안 보관합니다. 봇을 서버에서 제거하는 것만으로 설정 파일이 자동 삭제되지는 않습니다. 운영자는 서비스 제공이 끝나거나 삭제 요청을 확인하면 불필요한 설정을 삭제합니다.

**개인 언어와 임시 이용 정보**
개인 언어 선택과 반복 요청 제한 정보는 봇 재시작 시 초기화합니다. 개인 언어는 `/언어`·`/languages`에서 서버 기본값을 선택하여 해제할 수 있습니다. 개인 조작창과 진단창의 연결 정보는 창이 만료되거나 교체되는 경우, 또는 봇을 종료하는 경우에 정리합니다.

**문의 답변 연결 정보**
사용자 ID, 언어, 접수 번호와 접수 시각은 봇 종료 시 초기화됩니다. 답변 기능은 접수 후 7일간 유효하며, 만료된 연결 정보는 이후 문의 접수 과정에서도 정리합니다.

**Discord에 전달된 문의·신고·답변**
봇을 재시작해도 삭제되지 않습니다. 운영자는 문의 처리와 필요한 후속 확인이 끝나면 더 이상 필요하지 않은 기록을 직접 삭제합니다. 현재 봇에는 해당 메시지를 일정 기간 후 자동 삭제하는 기능이 없습니다.

**오류 로그와 리포트**
로컬 로그는 파일당 약 2MB, 백업 3개로 순환하며 오래된 기록부터 교체됩니다. 일수 기준의 자동 삭제 기능은 없습니다. Discord로 전송한 리포트도 재시작으로 삭제되지 않습니다. 운영자는 장애 확인이나 신고 처리에 필요하지 않게 된 기록을 직접 삭제합니다.

관계 법령에 따라 보관이 필요한 정보는 해당 목적과 기간에 한해 별도로 관리한 뒤 삭제합니다. 서비스 운영을 종료하는 경우에도 법적 보관 의무가 없는 정보는 지체 없이 삭제합니다.

봇이 보관하는 사본과 이용자가 Discord에 직접 게시한 원본 메시지는 구분됩니다. 원본 메시지나 첨부파일은 이용자 또는 해당 서버 관리자가 삭제해야 할 수 있으며, Discord의 보관 절차도 별도로 적용됩니다.

## 4. 이용자의 요청

이용자는 자신에 관한 정보의 열람, 정정, 삭제 또는 처리 정지를 요청할 수 있습니다. 문의하기의 일반 문의, `/문의`·`/contact` 또는 위 이메일로 요청할 수 있습니다. 봇이 중단되었거나 서버에 접근할 수 없는 경우에는 이메일을 이용해주세요.

요청에는 Discord 사용자 ID와 필요한 경우 서버 ID 또는 문의 접수 번호를 적어주세요. 운영자는 다른 사람의 정보를 보호하기 위해 필요한 범위에서 본인 여부와 요청 권한을 확인할 수 있습니다. 비밀번호나 봇 토큰은 요청하지 않습니다.

운영자는 관계 법령에 따라 요청을 처리합니다. 법적 보관 의무나 다른 사람의 권리 보호 때문에 요청을 전부 이행할 수 없는 경우에는 그 사유와 가능한 조치를 안내합니다.

정보 처리에 필요한 항목의 제공을 원하지 않으면 해당 기능의 이용을 중단할 수 있습니다. 필수 정보를 처리할 수 없는 경우 음악 재생이나 문의 답변이 제한될 수 있습니다.

## 5. 보호 조치

운영자는 실행 장치, 설정 파일과 수신 채널의 접근 권한을 관리하고, 업무에 필요한 담당자만 기록을 열람하도록 합니다. 오류 기록에는 봇 토큰이나 서명된 음원 주소가 남지 않도록 마스킹을 적용합니다.

삭제 대상 파일은 실행 장치에서 제거하고, 운영자가 관리하는 Discord 메시지는 삭제 권한 범위에서 정리합니다. 보관할 필요가 없어진 정보는 운영 환경의 사본과 백업에서도 관계 법령이 허용하는 범위 안에서 정리합니다.

개인정보 침해나 Discord API 데이터의 무단 접근이 의심되는 정황을 인지하면 사실 확인과 피해 확산 방지 조치를 진행합니다. Discord 개발자 약관과 관계 법령에 따라 Discord 및 영향을 받는 이용자에게 알리고 필요한 복구 조치를 합니다.

처리 항목, 이용 목적 또는 보관 방식이 변경되면 본 방침과 시행일을 갱신합니다. 중요한 변경은 공지 채널 또는 공개 안내 페이지에서 사전에 알립니다.

개인정보에 관한 문의와 권리 행사 요청은 위 연락처로 보내주세요.
